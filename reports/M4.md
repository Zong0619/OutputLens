# Milestone Report -- M4: Remaining Classifiers (A6, A7, A11, A12, A13)

**Date completed**: 2026-07-27
**Specification edition**: OutputLens Framework Specification Edition 1 (Candidate Standard)
**Report status**: Final

## Goals

Extend the classification layer with the Novelty axis (A6), implement claim
relationship mapping (A7), and add three synthesis analyzers (A11, A12, A13).

## Completed Work

### Deliverables

- [x] A6: Novelty Analyzer -- heuristic N1-N5 classification within knowledge boundary
- [x] A7: Claim Relationship Mapper -- conservative discourse-based graph construction
- [x] A11: Novelty Index Calculator -- N3+ proportion synthesis
- [x] A12: Overconfidence Detector -- confidence-vs-establishedness cross-reference
- [x] A13: Structural Integrity Analyzer -- foundation health, contradictions, orphans

### Knowledge Boundary Decisions

- **A6-001**: A6 evaluates novelty indicators from text signals only. Does not
  query external knowledge bases. Classifications are heuristic indicators,
  not verified novelty judgments.
- **A7-001**: A7 distinguishes discourse contrast (→ concedes) from logical
  contradiction (→ contradicts). Conservative mapping prioritizes precision
  over recall.

- **Synthesis layer**: A11, A12, A13 are pure computation from existing outputs

## Lessons Learned

1. **Novelty without external knowledge is inherently limited**: A6's heuristic
   approach correctly defaults to N5 for common knowledge. The knowledge boundary
   is preserved at the cost of classification granularity -- the right trade-off
   per the specification's design principles.

2. **Conservative relationship mapping works**: Distinguishing concedes from
   contradicts prevents false structural conflicts. The precision-over-recall
   approach produces cleaner graphs.
