## Architecture Impact

### Validated

- **A1→A2→A3 dependency chain**: The three-analyzer pipeline executes correctly
  through the orchestration layer. Transitive closure pulls in required analyzers.
- **Analyzer Contract**: A3 follows the same pattern as A2 -- single responsibility,
  explicit inputs (`AnalyzerInput("a1"), AnalyzerInput("a2")`), typed output.
- **Claim-based significance filtering**: Operationalized through position overlap
  detection. Validates the specification's "significance" requirement.

### No Impact

- Classification axes (A4/A5/A6) not yet tested
- Concept graph (A8) and coherence (A14) not yet tested

## Specification Validation

### Requirements Validated

- A3 output format: `list[Concept]` with all required fields populated
- Concept types: All 7 types producible (Phase 2.1: 4 entity types; Phase 2.2: domain_concept)
- Position traceability: All surface forms have valid start_char/end_char
- Cross-reference integrity: referencing_claim_ids validated

### Ambiguities Discovered

- **Concept type boundary**: distinguishing domain_concept from common_concept is
  inherently fuzzy. A3-004 documents the heuristic approach.
- **Significance filtering threshold**: single-claim reference is permissive.
  Stricter thresholds may be needed but require evaluation data.

## Known Limitations

- Single-word names not extracted (requires 2+ capitalized words)
- Organizations without suffixes require curated list entry
- Cross-paragraph coreference not supported
- Zero anaphora and cataphora not supported
- Domain association limited to curated keyword list
- Definition detection limited to explicit pattern matches

## Lessons Learned

1. **Named entity lists grow quickly**: The curated location/organization/person
   lists started small and grew with each failing test. This is inherent to
   knowledge-based approaches -- the lists will never be complete.
2. **Coreference is the hardest sub-problem**: Pronoun resolution requires
   gender/number agreement. Definite NP resolution requires role-to-type mapping.
   Both are fundamentally semantic tasks that rule-based approaches approximate.
3. **Domain association needs broader coverage**: The keyword mapping covers
   ~60 terms across 8 domains. Real AI responses span many more domains. This
   is a v3 enhancement area.
